# Fontes

Arquivos das três fontes da interface, guardados no repositório para que o build não dependa de rede.

| Arquivo                     | Fonte               | Licença | Origem                                           |
| --------------------------- | ------------------- | ------- | ------------------------------------------------ |
| `bricolage-grotesque.woff2` | Bricolage Grotesque | OFL 1.1 | `@fontsource-variable/bricolage-grotesque` 5.3.0 |
| `figtree.woff2`             | Figtree             | OFL 1.1 | `@fontsource-variable/figtree` 5.3.0             |
| `jetbrains-mono.woff2`      | JetBrains Mono      | OFL 1.1 | `@fontsource-variable/jetbrains-mono` 5.3.0      |

São as versões variáveis, só com os caracteres latinos. O texto da licença de cada uma está no arquivo
`*.LICENSE.txt` ao lado.
